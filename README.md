# ملفات تطبيق القوانين

مستودع المحتوى الذي يجلبه التطبيق: فهرس القوانين وملفات PDF.

```
index.json      ← فهرس القوانين (يحدد ما يظهر في التطبيق)
pdf/            ← ملفات PDF
tools/          ← أداة فحص الفهرس
```

> يجب أن يبقى المستودع **عامًا (Public)** ليتمكن التطبيق من التحميل.

## إضافة أو تفعيل قانون

1. ارفع ملف PDF إلى مجلد `pdf/` **بالاسم نفسه** المكتوب في حقل `file` في `index.json`
   (الأسماء حساسة لحالة الأحرف: `Constitution.pdf` ≠ `constitution.pdf`).
2. في `index.json` غيّر `"available": false` إلى `true` لذلك القانون.
3. احفظ (Commit). يظهر القانون للمستخدمين خلال دقائق بدون تحديث التطبيق.

أو شغّل محليًا بعد رفع الملفات لضبط الحقل تلقائيًا:

```
python tools/check_index.py --fix
```

## استبدال ملف بنسخة محدّثة

استبدل الـ PDF بنفس الاسم، ثم ارفع حقل `"version"` لذلك القانون في `index.json`
(أضفه إن لم يكن موجودًا؛ القيمة الافتراضية 1). المستخدمون يحمّلون النسخة الجديدة عند فتح القانون.

## قانون جديد في الفهرس

```json
{
  "id": "unique_id",
  "title": "اسم القانون",
  "file": "file_name.pdf",
  "icon": "gavel",
  "available": false
}
```

الأيقونات المدعومة معرّفة في التطبيق (`lib/models/law_icons.dart`)، وأي اسم غير معروف يظهر بأيقونة كتاب.

## ملاحظات

- ملفات أكبر من 100MB يرفضها GitHub، والأفضل أن يبقى الملف أقل من 50MB.
- الرفع من المتصفح محدود بـ 25MB للملف الواحد؛ للأكبر استخدم Git.
- GitHub يخزّن الملفات مؤقتًا قرابة 5 دقائق، فقد لا يظهر التعديل فورًا.
- يتحقق Workflow تلقائيًا عند كل رفع من صحة الفهرس ووجود الملفات المعلن توفرها.
